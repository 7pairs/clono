# Vivliostyleコラム検証用fixture

## 目的

コラムの変換後を模したHTML構造について、内部のMarkdown変換、Vivliostyleによる囲み枠の組版、ページ分割、脚注との結合を検証する。

このfixtureは著者向けの独自記法や、clonoの最終的な出力契約を確定するものではない。clonoの変換後候補として、`aside.column`と必須の`p.column-title`を入力する。

## 検証対象

- 必須のプレーンテキストタイトルを表示できる
- 複数段落、強調、インラインコード、リンク、箇条書き、番号付きリストを内部に記述できる
- コードブロック、画像、Markdown表を内部に記述できる
- 一ページに収まるコラムは、タイトルから末尾まで同じページに配置できる
- 一ページに収まらないコラムは、タイトルを繰り返さずに複数ページへ分割できる
- コラム内のPandoc風脚注を、本文の脚注と同じ連番で参照ページ下部へ表示できる
- コラム内脚注にインラインコードとリンクを記述できる
- 章ごとに脚注番号が1へ戻る

見出し、コラムの入れ子、コラムへのID参照・連番、複数種類のコラムは検証対象に含めない。

## 入力と出力の境界

コラムは補足的な内容を表す候補構造として`aside.column`を使用する。タイトルは目次に含まれる見出しとして扱われないよう、`p.column-title`とする。

内部のMarkdown変換と脚注構造の生成はVFM、囲み枠の表示、分割、脚注のページ下部への配置はVivliostyleとテーマCSSへ委譲する候補とする。

fixtureのclass名、HTML要素、枠線、背景色、余白は検証用であり、製品用テーマのデザインではない。

## 依存関係

- Node.js 22.13.0以降の22系、または24系
- `@vivliostyle/cli` 11.1.0
- `@vivliostyle/vfm` 2.7.0
- Vivliostyle.js 2.44.1: CLIが使用するバージョン
- `mupdf` 1.28.0

依存関係はこのディレクトリの`package-lock.json`に固定する。

## 検証済み環境と環境差

PDFの自動検証と目視確認は、次の環境で実施した。

- OS: macOS 26.5.2
- Node.js: 24.19.0
- PDFに埋め込まれた日本語フォント: ヒラギノ角ゴ ProN W3およびW6
- PDFに埋め込まれた等幅フォント: Osaka-Mono

テーマCSSは、特定の製品用フォントを検証対象にしないため、汎用ファミリーの`sans-serif`を指定する。解決されるフォントと文字メトリクスはOSによって異なるため、PDFの総ページ数と脚注の絶対座標は出力契約としない。

PDF検証では、短いコラムの開始と終了が同じページにあること、長いコラムの終了が開始より後のページにあること、脚注群が同じページの本文より下にあり本文領域から分離されていることなど、フォント差の影響を受けにくい相対的な条件を確認する。別の環境でページ数や改行位置が変化しても、これらの条件を満たす場合は検証成功とする。

## 実行方法

```shell
set -eu
npm ci
npm run verify
```

個別に確認する場合は、次のコマンドを使用する。

```shell
set -eu
npm run verify:webpub
npm run verify:pdf
```

生成物は`output/`に出力され、Gitの管理対象には含めない。

## 自動検証

`scripts/verify-webpub.mjs`は、次を確認する。

- コラムの`aside`、ID、class、必須タイトルが保持される
- タイトルが見出しにならない
- 強調、インラインコード、リンク、箇条書き、番号付きリストがHTMLへ変換される
- 構文強調付きコードブロック、画像、表がHTMLへ変換される
- コラム内脚注を含め、各章の脚注が参照順に連番となる
- 脚注本文がコラムの外に生成される
- 脚注内のインラインコードとリンクが保持される
- 第2章の脚注番号が1へ戻る

`scripts/verify-pdf.mjs`は、次を確認する。

- 短いコラムはタイトルから末尾まで同じページにある
- 長いコラムは複数ページへ分割され、タイトルは一度だけ表示される
- コラムの開始、中間、末尾の内容がPDFに存在する
- 本文とコラムから参照した脚注が、同じ参照ページの下部にある
- すべての脚注参照と戻りリンクが対応する対象へ解決され、コラム内と脚注内の外部リンクがPDFに保持される
- 第2章の脚注番号が1へ戻り、コラム内脚注へ連続する

PDFの総ページ数や、ページ高に対する固定比率は検証しない。脚注の配置は、同じページの本文より下にあり、脚注群とページ下端の間隔が本文と脚注群の間隔より小さいことによって確認する。

## 目視確認

`output/column.pdf`を開き、次を確認する。

- 枠線、背景色、余白が内部の文章やリストと重ならない
- コード、画像、表がコラムの横幅に収まる
- 長いコラムのページ境界で内容が欠落、重複、重なりを起こさない
- コラム内脚注が枠内ではなく、本文脚注とともにページ下部へ表示される
- 脚注内のインラインコードとリンクが表示される

## 未検証・未決定

- 著者向け記法と最終的なHTML出力契約
- 複数種類のコラムと種類ごとのデザイン

- コラムの途中にある脚注がページをまたぐ長さになった場合
