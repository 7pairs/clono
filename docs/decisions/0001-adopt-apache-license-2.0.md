# 0001: Apache License 2.0を採用する

- 状態: 採用
- 決定日: 2026-08-13

## 背景

`clono`では、商用・非商用を問わず、利用者による自由な利用、改変、再配布を認めたい。一方で、派生物への同一ライセンスの適用やソースコードの公開は要求せず、ソフトウェアを無保証で提供し、その利用によって生じた損害に対する責任を、適用法で認められる範囲において制限したい。

また、将来コントリビューションを受け入れる可能性を考慮し、著作権だけでなく、各コントリビューションの利用に必要となる貢献者の特許についても、明示的な許諾を扱えることが望ましい。

## 決定

`clono`のライセンスとしてApache License 2.0を採用する。

著作権者の表示には、次の表記を使用する。

```text
Copyright 2026 HASEBA Junya (7pairs)
```

## 理由

- 商用利用を含む利用、改変、再配布を広く認める許容型ライセンスである
- 派生物への同一ライセンスの適用やソースコードの公開を要求しない
- 無保証および責任制限を定めている
- 各コントリビューションの利用に必要な範囲について、貢献者から利用者への明示的な特許許諾を含む
- 本ソフトウェアまたはコントリビューションに関する特許侵害訴訟を提起した場合に、特許許諾を終了する条項を備えている
- 広く利用されており、利用者がライセンス条件を確認しやすい

## 比較した候補

### MIT License

要件を満たす許容型ライセンスであり、条文が短く扱いやすい。一方、Apache License 2.0のような明示的な特許許諾を含まないため、採用しない。

### BSD 2-Clause License

要件を満たす許容型ライセンスである。一方、Apache License 2.0と比較した場合に、`clono`にとって明確な利点がなく、明示的な特許許諾も含まないため、採用しない。

### GPL系ライセンス

利用、改変、再配布の自由を保証する一方、対象となる派生物を配布する際に同じライセンス条件の適用やソースコードの提供を求めるコピーレフトの方針が、利用者にライセンス上の選択肢を広く残したいというプロジェクトの意図に合わないため、採用しない。

## 影響

- `clono`の配布物にはApache License 2.0の全文を含める
- 再配布者には、ライセンス本文の同梱、変更したファイルへの告知、既存の著作権・特許・商標・帰属表示の保持など、Apache License 2.0が定める条件が課される
- `NOTICE`ファイルを配布物に含める場合、再配布者には、その中の該当する帰属表示を引き継ぐ条件が追加される
- 派生物は、Apache License 2.0の条件を満たす限り、異なるライセンス条件で配布できる
- 無保証および責任制限は、適用法で認められる範囲に限られる

## 見直す条件

次のいずれかが生じた場合は、この決定を見直す。

- 採用する依存関係とのライセンス互換性に重大な問題が判明した場合
- 配布形態またはコントリビューション方針の変更により、異なるライセンスが適切になった場合
- 法令または主要な配布プラットフォームの要件変更により、現在の方針を維持できなくなった場合
