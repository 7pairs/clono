# clono著者向け記法

- 状態: 策定中
- 作成日: 2026-08-22
- 最終更新日: 2026-08-22

## 目的

この文書は、`clono`を利用する著者が原稿に記述できる記法と、その開発状態の正本である。`clono`の独自記法だけでなく、Thunder Clawの書籍制作に必要だが、標準Markdown、VFM、VivliostyleまたはテーマCSSへ委譲するため`clono`独自記法の対象としない機能も記録する。

Vivliostyleと`clono`の責務分担は、[Vivliostyleとclonoの責務整理](../vivliostyle-responsibilities.md)を正本とする。この文書では調査根拠を重複して記述せず、著者向けの入力方法と実装状態を示す。

## 状態の定義

| 状態 | 意味 |
| --- | --- |
| 検討前 | 必要性と責務は把握しているが、著者向け記法と詳細仕様をまだ検討していない |
| 仕様策定中 | 候補記法または要件を検討しており、実装契約が確定していない |
| 実装予定 | 著者向け記法と実装契約は確定したが、実装または自動テストが完了していない |
| 実装済み | 仕様に対応する実装と自動テストがあり、利用できる |
| 保留 | 将来再検討し得るが、現在の開発対象に含めない |
| 対象外 | `clono`独自記法または変換を実装せず、標準Markdown、VFM、Vivliostyle、テーマCSSなどへ委譲する |

`clono`の機能として必要ないと判断した場合は「対象外」とし、必要性はあるが初期開発で扱わない場合は「保留」とする。「対象外」は、書籍制作でその機能を利用できないことを意味しない。

## 記法一覧

### 基本表現

| 機能 | 著者向け記法 | 状態 | 実現方法 |
| --- | --- | --- | --- |
| 意図的な空行 | 未定 | 検討前 | `clono`が著者向け記法を空白用の構造へ変換し、表示をテーマCSSへ委譲する候補 |
| 強制改行 | 行末の`\` | 対象外 | 標準Markdownの強制改行をそのままVFMへ渡す |
| 強制改ページ | 未定 | 検討前 | `clono`が著者向け記法を改ページ用の構造へ変換し、改ページをテーマCSSへ委譲する候補 |
| 複数段落の右寄せ | `:::align{position="right"}`と`:::`で囲む（候補） | 仕様策定中 | `clono`が複数段落を保持する右寄せ用コンテナへ変換し、文字揃えをテーマCSSへ委譲する候補 |
| 定義リスト | 未定 | 検討前 | `clono`が著者向け記法を`dl`、`dt`、`dd`構造へ変換する候補 |
| コラム | 未定 | 検討前 | `clono`が必須タイトルと複数のブロックを保持するコンテナへ変換し、外観とページ分割をテーマCSSへ委譲する候補 |

### 脚注、ID、番号、参照

| 機能 | 著者向け記法 | 状態 | 実現方法 |
| --- | --- | --- | --- |
| 脚注 | `[^id]`と`[^id]: 脚注本文` | 対象外 | Pandoc風の脚注記法を壊さずVFMへ渡し、脚注構造への変換とページ下部への配置をVFMとVivliostyleへ委譲する |
| 見出しID | `# 見出し {#identifier}` | 対象外 | VFMの明示的なID記法をそのまま使用する |
| 番号付き画像 | 未定 | 検討前 | `clono`がID、画像、キャプションを持つ`figure`構造へ変換する候補。番号なし画像には標準Markdownを使用する |
| 番号付き表 | 未定 | 検討前 | `clono`がID、Markdown表、キャプションを持つ`figure`構造へ変換する候補 |
| 番号付きコードリスト | 未定 | 検討前 | `clono`がID、コードフェンス、キャプションを持つ`figure`構造へ変換する候補。番号なしコードブロックには標準Markdownを使用する |
| 見出し、画像、表、コードリストの連番 | なし | 対象外 | 番号の生成をVivliostyleとテーマCSSのカウンターへ委譲する |
| 番号の参照 | 未定 | 検討前 | `clono`が参照種別とIDを検証し、番号参照用のリンク構造へ変換する候補 |
| 番号とタイトルの参照 | 未定 | 検討前 | `clono`が参照種別とIDを検証し、番号とタイトルの参照用リンク構造へ変換する候補 |

### 生成機能

| 機能 | 著者向け記法 | 状態 | 実現方法 |
| --- | --- | --- | --- |
| 目次 | なし | 対象外 | 目次項目、番号、ページ番号、リンクの生成をVivliostyleの自動目次へ委譲する。原稿順序、文書種別、掲載有無の入力契約は著者向け記法とは別に検討する |
| 索引項目の指定 | 未定 | 検討前 | `clono`が索引語と読みを収集し、読みの正規化、分類、並べ替え、項目の統合、索引マーカーの生成を担う候補 |
| 索引文書の生成 | 原稿内の直接の記法はなし | 検討前 | `clono`が収集した索引項目から索引文書を生成し、ページ番号とPDF内部リンクの生成をVivliostyleへ委譲する候補 |

## 更新方針

- 著者向け記法または実装契約を決定した場合は、この文書の対応する状態、記法、実現方法を同じPull Requestで更新する
- 「実装済み」に更新する場合は、仕様に対応する実装と自動テストが同じPull Requestに存在することを確認する
- 詳細仕様は、規模が小さい間はこの文書に追記する。索引や相互参照などの大きな機能は個別の仕様文書へ分離し、一覧から参照する
- 調査結果によって責務判断が変わった場合は、[Vivliostyleとclonoの責務整理](../vivliostyle-responsibilities.md)と関連する調査記録を先に、または同時に更新する
