# 脚注の参照ページ

## 目的

複数ページの原稿で、GFM風脚注の定義を原稿末尾にまとめた場合に、VFMの`dpub`および`gcpm`モードによる脚注が、それぞれ対応する参照ページへ配置されるかを確認する。

## 入力とCSS

一ページ目と二ページ目から一件ずつ脚注を参照し、二件の脚注定義を原稿末尾へ参照順に記述する。

`footnotes.css`は共通CSSを読み込み、ページ脚注と検証用の強制改ページに必要な指定だけを加える。

```css
.footnote {
  float: footnote;
}

h2 {
  break-before: page;
}
```

`h2`は一つだけであり、この指定によって二つ目の節が必ず二ページ目から始まる。

## 実行方法

`research/vivliostyle-capabilities/`で、HTMLとPDFを生成する。

```console
npm run build:footnotes:reference-page
```

個別に生成する場合は、次のコマンドを使用する。

```console
npm run build:footnotes:reference-page:html
npm run build:footnotes:reference-page:pdf
```

生成物は`output/footnotes/reference-page/`へ出力され、Git管理対象には含まれない。

HTMLは直接固定した`@vivliostyle/vfm` 2.7.2で生成する。
PDFはVivliostyle CLI 11.1.0を通じて生成するため、CLIが内蔵する`@vivliostyle/vfm` 2.7.0がMarkdownの変換に使用される。

## HTMLの結果

2026-08-08に標準条件で実行し、次の結果を確認した。

### `dpub`

- 一ページ目と二ページ目の本文へ、番号1および2を含む`a[role="doc-noteref"]`を出力した
- 二件の`aside.footnote[role="doc-footnote"]`を、二ページ目の本文に対応する要素より後へまとめて出力した
- 各参照と脚注本体を、一意なIDと`a[role="doc-backlink"]`で相互参照した

### `gcpm`

- 一件目の`span.footnote[role="doc-footnote"]`を一ページ目の参照位置へ出力した
- 二件目の`span.footnote[role="doc-footnote"]`を二ページ目の参照位置へ出力した
- 参照番号、脚注番号および相互リンクはHTMLへ出力しなかった

Vivliostyle CLI内蔵VFM 2.7.0の中間HTMLについても、脚注に関係する構造はVFM 2.7.2の結果と一致した。

## PDFの結果

| 項目 | `dpub` | `gcpm` |
|---|---|---|
| ページ数 | 2 | 2 |
| 一件目の脚注 | 参照と同じ一ページ目の脚注領域 | 参照と同じ一ページ目の脚注領域 |
| 二件目の脚注 | 参照と同じ二ページ目の脚注領域 | 参照と同じ二ページ目の脚注領域 |
| ページをまたぐ番号 | 1、2と連続 | 1、2と連続 |
| 参照関係 | リンク付き番号と戻りリンクを保持 | 明示的なリンクなし |

両モードとも、各ページに脚注領域の区切り線を一本ずつ生成した。日本語、本文および脚注に欠落、文字化け、重なりまたは切れはなく、PDFから抽出したテキストでも各脚注は対応する参照と同じページに含まれた。

`dpub`では、二件の脚注本体がHTML上では二ページ目の本文より後にまとめて配置されているにもかかわらず、PDFでは一件目が一ページ目、二件目が二ページ目へ分かれた。この結果から、少なくとも本ケースでは、HTML上の脚注本体の位置だけで紙面上の脚注ページが決まるわけではないことが分かる。Vivliostyleがページを対応付ける内部機構までは本ケースから断定しない。

Popplerで`dpub`のPDFを検査した際、これまでのケースと同じname tokenの長さに関する警告が出た。`gcpm`では警告は出なかった。

## 暫定的な判断

原稿末尾にGFM風脚注の定義をまとめた複数ページの原稿でも、`dpub`と`gcpm`の両方が短い脚注を対応する参照ページへ配置できる。このケースのために、clonoが脚注定義を参照位置へ移動したり、ページを判定したりする必要はない。分類は「clono不要」、確信度は高とする。

`dpub`は本ケースでもページ脚注の候補から脱落しなかった。次に、一ページの脚注領域へ収まらない長い脚注の配置、分割および内容保持を比較する。

このケースでは、各ページの脚注を一件かつ短文とし、脚注定義の順序を参照順に揃えている。定義順が異なる場合、同じ脚注の複数参照および長い脚注は別途検証する。
