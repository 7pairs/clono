## 3. ライセンス本文から確認できる条件

### 3.1 MIT

[MIT本文](https://opensource.org/license/mit)は、利用・コピー・改変・結合・公開・配布・サブライセンス・販売を許可している。コピーまたは重要な部分に、著作権表示と許諾文を含める条件がある。

ソース公開や変更内容の表示を義務付ける明文はない。商用利用と、ソースを公開しない形での組み込み・再配布を候補から外す条件は見当たらない。ただし、非公開の形でも表示条件がなくなるわけではない。

特許許諾・特許訴訟による終了について、独立した明文の条項はない。この観察から「特許について一切許諾されない」「特許の問題がない」といった法的結論は出していない。

本文は無保証と責任制限を定め、冒頭に年と著作権者を記載する欄がある。

### 3.2 Apache License 2.0

[Apache-2.0本文](https://www.apache.org/licenses/LICENSE-2.0)第2・4節は、改変や、ソース・オブジェクト形式での再配布を認める。第4節は、ライセンスの提供、変更ファイルへの明確な変更表示、配布する派生物のソースで関連する既存の表示を保持することを条件にする。

元の配布物にNOTICEが含まれる場合は、関連する帰属表示の引き継ぎも必要になる。第4節はNOTICEの扱いを定めているが、すべての採用者に新規NOTICEの作成を一律に要求しているわけではない。

ライセンスの適用対象となる著作物（原文のWork）を、以下「対象著作物」と呼ぶ。

第3節は、貢献者が許諾できる特許請求項のうち、その貢献単独、または提出先の対象著作物との組み合わせによって必然的に侵害されるものを対象に許諾する。所定の特許訴訟を起こした場合、その対象著作物について与えられた特許許諾が終了する。あらゆる第三者特許への保証ではない。

第6節は商標利用の許可を限定し、第7・8節は無保証と責任制限を定める。著作権・ライセンス表示を残すことと、作者による推薦や商標利用の許可は同一ではない。

### 3.3 非公開利用と適用方法の補足

[ASF FAQ](https://www.apache.org/foundation/license-faq.html#Distribute-changes)は、変更したコードを非公開にでき、変更をASFへ提供する必要はないと説明している。商用・非公開の利用を許容する希望と整合する候補である。ただし、再配布時には本文の条件に従う。

同FAQの[自作ソフトへの適用案内](https://www.apache.org/foundation/license-faq.html#Apply)は、LICENSEへの全文の配置、NOTICEの検討、ファイル単位のヘッダを案内し、著作権表示とSPDX識別子による短い例も示している。

[REUSE FAQ](https://reuse.software/faq/)は、著作権者とSPDX識別子を用いたファイル単位の表示、READMEでの案内、コメントできないファイルに対応する別ファイルでの表示などを紹介している。年には初回公開年、最新公開年、範囲などの選択肢を挙げている。

今回の参考になるのは、ファイルが単体で参照されても、作者とライセンスを判別できるようにする考え方である。年の選択や、各形式への表示方法はまだ採用していない。

短いヘッダやSPDX識別子だけで、配布時に必要なライセンス本文の提供まで不要になるとは扱わない。公式本文、ファイルごとの表示、READMEの案内を、それぞれの役割で検討する。
